# Project Synopsis
## Autonomous Smart Agriculture Disease Detection

### Team Winters T66 | GLA University | B.Tech CS AIML and IIoT

## The Problem
Crop diseases spread fast and farmers notice them too late.
Manual checking is slow and needs experts.

## Our Solution
1. Farmer takes a photo of a crop leaf
2. AI model detects the disease in under 3 seconds
3. System shows the disease name and confidence score
4. System gives treatment advice to the farmer
5. Works without internet on Raspberry Pi

## Technology Used
- AI Model: CNN using MobileNetV2
- Dataset: PlantVillage with 38 disease types
- Backend: Flask Python server
- Frontend: Streamlit web dashboard
- Edge Device: Raspberry Pi 4

## Our Goals
- Model accuracy 85 percent or more
- Detection in 3 seconds or less
- Cost under 25 dollars for hardware
