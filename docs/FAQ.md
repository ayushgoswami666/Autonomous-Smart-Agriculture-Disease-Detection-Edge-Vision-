# Frequently Asked Questions

## Q1. What crops does this system support?
Currently supports 38 disease classes from the PlantVillage dataset including Tomato, Potato, and Corn.

## Q2. Does it work without internet?
Yes! The edge inference on Raspberry Pi works fully offline.

## Q3. What is the minimum hardware required?
Raspberry Pi 4 with a camera module and 4GB RAM recommended.

## Q4. How accurate is the model?
Target accuracy is 85% or above on the validation dataset.

## Q5. Can I add more diseases?
Yes, retrain the CNN model with additional labeled data and redeploy.
